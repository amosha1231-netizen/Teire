# שאלות להיכלי פרשת השבוע

השאלות המוכנות מראש לששת ההיכלים (רש"י, רמב"ן, בעל הטורים, אבן עזרא, ספורנו, אור החיים) נמצאות ב-`content/parasha.js`, ברשימה `WEEKS`. לכל פרשה יש `shabbat` (התאריך של שבת שבה קוראים אותה) ו-`q` עם שאלות לכל פרשן.

הכלים כאן עוזרים לכתוב שאלות שמבוססות על לשון הפרשן עצמו, ולא מהזיכרון.

## איך מוסיפים פרשה

1. מורידים את הטקסטים של החומש (פעם אחת, לתיקייה `src/` שלא נשמרת בגיט):

   ```bash
   python3 scripts/parasha/fetch.py Genesis      # Exodus, Leviticus, Numbers, Deuteronomy
   ```

2. קוראים את הפרשנים על הפרשה (פרק:פסוק עד פרק:פסוק, ואורך מקסימלי לכל דיבור):

   ```bash
   BOOK=Genesis python3 scripts/parasha/show.py rashi 37:1 40:23 200
   ```

   הפרשנים: `rashi`, `ramban`, `ibn`, `sforno`, `oh` (אור החיים), `bht` (בעל הטורים), ו-`torah` לפסוקים.

3. כותבים קובץ שאלות ב-`weeks/` (ראו `weeks/vayishlach.py`). בכל שאלה `a[0]` היא התשובה הנכונה, והמחולל מערבב את הסדר. `quote` חייב להופיע מילה במילה אצל הפרשן על אותו פסוק (אפשר לדלג על קטע עם `...`).

4. מייצרים את הבלוק ובודקים:

   ```bash
   python3 scripts/parasha/gen.py scripts/parasha/weeks/vayeshev.py > /tmp/vayeshev.js
   ```

   המחולל ממלא את הפסוק מהתורה (בלי טעמים, עם ה׳ במקום השם), כותב את המקום בעברית, ומדפיס `!!` על כל ציטוט שלא נמצא אצל הפרשן. מתקנים עד שאין `!!`, ומדביקים את הבלוק לסוף `WEEKS` ב-`content/parasha.js`, לפי סדר התאריכים.

## כמה שאלות

ברירת המחדל לכל פרשה: 13 לרש"י (שלבים 1 עד 3) ו-6 לכל פרשן אחר (שלבים 1 ו-2). כל משימה בוחרת 5 שאלות מהשלב.
